## ✨ 功能

- 🎯 **一键预约** — 留下联系方式，24小时内我们联系你
- 👩‍⚕️ **专业陪诊** — 培训过的陪诊师，不是随便找人
- 🏥 **医院全覆盖** — 北京/天津主要三甲医院均可
- 💊 **用药管理** — 协助整理处方和复查事项
- 📱 **实时反馈** — 陪诊全程照片+状态更新
- 🔒 **验证 & 保险** — 所有陪诊员背景核查+意外险

---

## 📱 如何使用

1. **填写表单** → 告诉我们患者情况和就诊需求
2. **我们联系你** → 24小时内通过微信确认细节
3. **医院碰面** — 陪诊员在医院接患者
4. **实时更新** → 就诊全程照片+状态推送给你
5. **就诊报告** → 结束后发送完整陪诊记录
